# OneMana

We make **[OneCamp](https://onemana.dev)**: chat, docs, tasks, boards, video calls, a calendar and your
Gmail in one workspace you run yourself, with AI teammates you can govern. Agents act as the person
who sponsors them and never more, ask before they change things, and every action they take is
signed and recorded.

**Open source.** The server is AGPL-3.0 and the web app is MIT. A commercial licence is available
for companies that cannot accept AGPL.

| Repository | What it is |
|---|---|
| [OneCamp](https://github.com/OneMana-Soft/OneCamp) | The server (Go). `main` has AI teammates, `without-ai` has no AI at all. |
| [OneCamp-fe](https://github.com/OneMana-Soft/OneCamp-fe) | The web app (Next.js). |
| [OneCamp-desktop](https://github.com/OneMana-Soft/OneCamp-desktop) | Windows, macOS and Linux app. |

- **Try it:** [live demo](https://onemana.dev), no signup.
- **Run it:** [free licence](https://onemana.dev/free) with a one-command installer, or build it from source.
- **Docs:** [onemana.dev/docs](https://onemana.dev/docs)
