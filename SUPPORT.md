# Getting help

- **Something broken?** Open an issue with the "Something is broken" form.
- **Setup or "how do I" questions:** [Discussions](https://github.com/OneMana-Soft/OneCamp/discussions).
- **Documentation:** [onemana.dev/docs](https://onemana.dev/docs) covers installing, updating, DNS, backups, agents and integrations.
- **Lifetime licence or OneCamp Cloud customers:** email **support@onemana.dev** for direct help.
- **Security problems:** report them [privately](https://github.com/OneMana-Soft/OneCamp/security/advisories/new), never in a public issue.
